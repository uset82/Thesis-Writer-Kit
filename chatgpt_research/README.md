# ChatGPT & External AI Research Archive

> Storage directory for importing prior ChatGPT chat exports, brainstorming conversations, preliminary outlines, and research notes.

---

## Directory Organization

```
chatgpt_research/
├── transcripts/        # Raw exported chat transcripts (.json or .md)
├── outlines/           # Early brainstormed outlines and chapter ideas
└── summaries/          # Synthesized notes and concept maps
```

---

## How to Import Your Data

1. **ChatGPT Conversation Export:** Save your previous chats as Markdown (`.md`) or text (`.txt`) in `transcripts/`.
2. **Outlines:** Place any existing thesis structures or draft proposals in `outlines/`.
3. **Usage with Agents:** Reference any imported file when initiating a draft (e.g. `Use my notes from chatgpt_research/outlines/intro_ideas.md to draft the introduction`).
